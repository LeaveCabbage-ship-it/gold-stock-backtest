# 金股组合收益率对比工具

这是一个本地 Streamlit 工具，用于比较每月等权调仓的金股组合与沪深300、计算机（申万）、科创50、创业板指的累计收益率。

## 推荐启动方式：Streamlit

用 VS Code 打开本目录，在终端运行：

```powershell
python -m pip install -r requirements.txt
python -m streamlit run streamlit_app.py
```

如果当前 VS Code 已选择安装了 Streamlit 的 Python 环境，也可以双击 `start_streamlit.bat`。

整个工具目录可以直接移动到 D 盘。移动后用 VS Code 打开新的目录，再在已选择的 Python 环境中运行上述命令即可。

## 回测口径

- 基准日必须等于最早一行调仓日。
- 第一行调仓日自动跟随基准日，不需要重复填写。
- 每一行表示该日收盘后生效的金股组合。
- 组合从该调仓日收盘持有至下一调仓日收盘，资金在当期股票中等权分配。
- 下一调仓日收盘后，组合重新等权分配。
- 月末、截止日或停牌日没有行情时，使用该日之前最近一个可用收盘价。
- 行情仅通过同花顺官方数据接口获取，不使用新浪、腾讯、东方财富、Tushare 或 AkShare 行情接口。
- 页面需要填写同花顺数据接口 `refresh_token`。Token 仅保存在当前会话内存中。
- 沪深京股票均通过同花顺官方历史行情接口获取。
- 金股可以输入 6 位股票代码，也可以输入股票名称。
- 页面可选择股票价格口径：不复权 `CPS=1`、前复权 `CPS=2`、后复权 `CPS=3`。默认使用前复权。
指数代码可以在界面中修改。默认使用同花顺证券代码：沪深300 `000300.SH`、计算机（申万）`801750.SL`、科创50 `000688.SH`、创业板指 `399006.SZ`。

指数列表支持增删。可以输入指数名称，也可以输入同花顺代码；运行后页面会显示指数名称与代码映射表。

## 数据留存

- 股票池和行情仅在当前会话的内存中使用，不写入数据库。
- 只有用户主动下载 Excel 或 PNG 时，结果文件才会保存到浏览器下载目录。
- Streamlit 会在当前浏览器会话中保留页面状态；关闭服务后状态消失。

## 部署

若希望把链接分享给其他人，可以把本目录上传到 GitHub 后部署到 Streamlit Community Cloud。入口文件选择 `streamlit_app.py`。

## 使用步骤

1. 输入基准日和截止日期。
2. 在首行填入基准日收盘后持有的金股代码。
3. 用“新增下个月”添加月末调仓行，也可以添加任意调仓日。
4. 点击“运行回测”。
5. 在表格和对比图中查看结果，并按需导出 Excel 或 PNG。

页面和 Excel 均包含累计收益率、月度收益率变化、指数对比和金股逐月贡献明细。贡献明细显示股票名称、代码和实际取价交易日，便于逐月复核。
